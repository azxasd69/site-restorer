Восстановление сайта на WordPress из архива

Обновлено 10 ноября 2026 Чтение: 8 минут CMS: WordPress

Коротко

  1. WordPress = файлы + база. Архив отдаёт страницы и часть файлов темы, базы там нет.
  2. Медиатека — главная потеря: wp-content/uploads обходится редко.
  3. Тема восстанавливается частично: вёрстку видно, PHP-шаблоны — нет.
  4. Плагины не восстановить по HTML: видно только их следы на странице.
  5. Порядок: база → wp-content → тема → медиа → домен.

Сайт на WordPress состоит из двух половин: файлов в wp-content и записей в базе. Из веб-архива приходит то, что видит посетитель, — и этого достаточно, чтобы сохранить контент и трафик, но недостаточно, чтобы вернуть редактор, плагины и медиатеку.

1. Из чего состоит сайт на WordPress

ЧастьГде живётЕсть ли в архиве
Записи и страницыбаза данныхнет, только текст на страницах
Настройки, меню, виджетыбаза данныхнет
Темаwp-content/themes/<имя>частично: CSS и картинки
Плагиныwp-content/pluginsнет, только результат в разметке
Медиатекаwp-content/uploadsчастично, зависит от обхода
Ядроwp-admin, wp-includesнет смысла: скачивается заново

Вывод простой: без базы сайт не станет управляемым. Без файлов темы он не будет выглядеть как раньше. Архив даёт третье — читаемый контент по прежним адресам.

2. Путь с бэкапом

Если есть дамп базы и архив wp-content, восстановление занимает часы:

  1. Чистая установка WordPress той же или ближайшей мажорной версии.
  2. Импорт дампа базы.
  3. Замена wp-content на копию из бэкапа.
  4. Проверка префикса таблиц в wp-config.php.
  5. Обновление адресов в базе, если домен сменился.
  6. Проверка постоянных ссылок: если они не открываются, пересохраните настройки.

Частая ловушка: дамп старый, а файлы новые (или наоборот). Тогда часть картинок не находится: записи ссылаются на файлы, которых нет, и наоборот. Перед публикацией пройдитесь по медиатеке и проверьте десяток последних записей.

3. Путь без бэкапа: статическая копия

Без базы WordPress не поднять, но контент вернуть можно:

  1. CDX-выгрузка всех адресов с фильтром по text/html.
  2. Загрузка страниц в режиме id_, чтобы ссылки вели на оригинальный домен.
  3. Переписывание ссылок на относительные, приведение кодировок.
  4. Публикация по тем же адресам.

Такой сайт не редактируется через админку, но читается, индексируется и держит трафик. Для блога или сайта услуг этого часто достаточно, чтобы не потерять аудиторию, пока готовится нормальная версия.

4. Тема и стили

В HTML видны подключённые файлы темы: ищите пути вида /wp-content/themes/<имя>/style.css и версию в параметрах.

  • Скачайте style.css, шрифты и изображения темы по этим адресам.
  • Проверьте, платная тема или бесплатная: бесплатную можно поставить заново из каталога, платную — только из своей копии.
  • Дочерняя тема: правки обычно в ней, а не в родительской. Ищите -child в имени каталога.
  • Кастомайзер хранит настройки в базе — их из архива не вернуть, внешний вид придётся подбирать по снимкам.

5. Медиатека

uploads — самая пострадавшая часть. Причины те же, что и везде: отложенная загрузка, CDN, бюджет обхода.

ИсточникЧто даётРеалистичность
Бэкап wp-contentвсё, включая миниатюрылучший вариант
Архивчасть файлов по прямым адресамобычно меньшая половина
Письма с вложениямиотдельные изображениянизкая
Повторная загрузка из первоисточникаоригиналызависит от типа контента

Оценка до работ — один запрос в CDX с фильтром mimetype:image/.*. Если строк мало, планируйте пересборку медиа, а не восстановление.

Частые вопросы

Можно ли восстановить WordPress из одного архива?

Только как статический сайт: страницы будут открываться, но админки, плагинов и базы не будет. Управляемый сайт требует дампа базы.

Где в архиве искать файлы темы?

По путям /wp-content/themes/<имя>/ в HTML. Стили и изображения темы часто сохраняются, PHP-шаблоны — нет, их восстанавливают из бэкапа или ставят тему заново.

Почему в медиатеке пусто?

wp-content/uploads обходится редко: файлы грузятся отложенно, отдаются с CDN или не попадают в бюджет обхода. Проверить объём можно запросом в CDX по типу image/.

Что важнее сохранить в первую очередь?

Дамп базы. Записи, настройки и меню — это база; файлы темы и медиа можно добрать позже, а без базы сайт не станет управляемым.

Вернутся ли формы и комментарии?

Комментарии хранятся в базе, поэтому только с дампом. Формы — это плагин; по HTML видно, какой именно, но восстановить его можно только установкой заново.
