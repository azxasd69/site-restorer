What support pays for

Five lines that actually cost money. While there is no support, these expenses come out of the author's pocket or get postponed.

Code signing certificate top priority

Windows shows “Windows protected your PC” on every launch of an unsigned exe. A code signing certificate costs money, and the price depends on the issuer and the checks.

The first barrier a new user meets, and it is visible to everyone on Windows 10 or 11.

32-bit and Linux test stands

The 32-bit build and the Linux window are checked on real machines: a virtual machine does not show how dialogs, fonts and display scaling behave.

Windows 7 and 8 are not in the requirements: that is an open question, not a promise.

Domain and site hosting

The lastcopy.ru domain and hosting for the landing page, the guides and the download pages. Releases themselves live on GitHub for free; everything else is a recurring line.

So that the site opens even when GitHub is unreachable.

Troubleshooting reports

Every case of “I got 60 % and the files are broken” means a run on the problematic domain, an inventory dump and a hunt for the cause: encoding, an archive stub, a CMS cache.

One detailed investigation takes an hour to an evening.

macOS: Apple signing

macOS builds come out of CI (arm64 and x64), but without signing and notarisation Gatekeeper blocks the launch. An Apple Developer subscription is a separate line.

Not funded yet, which is why launching requires a workaround.

Other ways to help

What if I would rather not donate
Help is not only money: a GitHub star, a bug report with a sample domain and a log, or a check of the build on your system saves as much time as 500 ₽.
Payment requires a Boosty account
Yes: the donation form opens only after signing in, and registration is free and takes half a minute. If you need another way, write to GitHub Issues.
Are donations taxable
Under Boosty's rules donations are the only payout category that is not taxable for the author; subscriptions and sales count as income.
Where can I see what the money was spent on
In the project blog: notes about expenses and releases. The planned lines are listed above — if support does not cover them, the build ships unsigned.
Will there be paid versions
No. The MIT licence and the design (a single binary with no server side) rule out paid editions: anyone can build the app.
