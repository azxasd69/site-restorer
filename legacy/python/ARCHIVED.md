# Архив: версия на Python

Эта реализация больше **не разрабатывается, не собирается в CI и не попадает
в релизы**. Актуальная версия — Rust в корне репозитория (`src/`): то же окно,
тот же CLI, но один самодостаточный бинарник.

Код оставлен как история: по нему видно, откуда пришли алгоритмы (разбор адреса,
инвентарь CDX, AIMD-конкурентность, перекодировка, отчёт).

Сборка из этого каталога не поддерживается: `build.ps1` оставлен для археологии
и может не работать с текущими версиями PyInstaller.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — алгоритмы и обоснования решений.
