# Сколько страниц может быть в индексе CDX веб-архива

| Поле | Значение |
|---|---|
| Статус | выполнено |
| Версия | 1.0 |
| Дата | 15.11.2026 |
| Основание | вопрос владельца: «А сколько страниц индекса архива может быть? может быть больше 3?» |
| Область | CDX API Wayback Machine (`showNumPages=true`) и обработка числа страниц в `site-restorer` 3.6.5 (`src/core.rs`) |

## 1. Вывод

**Да, страниц индекса может быть намного больше 3.** В Wayback Machine число страниц индекса (`numpages`) не ограничено сверху и растёт пропорционально числу архивных записей домена и его поддоменов (каждая страница соответствует zipnum-блоку индекса). На небольших корпоративных сайтах это единицы страниц (`3`–`4`), на средних — десятки (`20`), на крупных и старых доменах — **сотни и тысячи** (`989` у `nginx.org`, `5 401` у `lenta.ru`).

## 2. Замеры `showNumPages=true` по реальным сайтам

| Домен | `showNumPages` (замер) | Когда и чем проверено | Комментарий |
|---|---|---|---|
| `prokupol.ru` | **3** | 15.11.2026 и 11.11.2026, прямой запрос CDX (`matchType=domain`) | 518 + 969 + 152 = 1639 адресов (15.11.2026) |
| `rufence.ru` | **4** | 15.11.2026, прямой запрос CDX (`matchType=domain`) | — |
| `info.cern.ch` | **20** | 15.11.2026, прямой запрос CDX (`matchType=domain`) | подтверждено также в `plans/2026-11-release-364.md` |
| `nginx.org` | **989** | 15.11.2026, прямой запрос CDX (`matchType=domain`) | 11.11.2026 в `docs/index-completeness.md` было `98` — индекс растёт, зависит от нагрузки/объёма архива |
| `lenta.ru` | **5 401** | 11.11.2026, `docs/index-completeness.md` §1 | 15.11.2026 запрос к `lenta.ru` и `example.com` упал по таймауту 15 с |

## 3. Как `site-restorer` 3.6.5 работает с любым числом страниц

| Показатель / настройка | Значение в коде | Где в `src/` | Поведение |
|---|---|---|---|
| Порог обхода по умолчанию | `DEFAULT_INDEX_MAX_PAGES = 200` | `src/core.rs:73` | Защита, чтобы крупный портал (`5 401` стр.) не обходил весь индекс часами |
| Параметр CLI для изменения порога | `--index-max-pages <N>` (`0` — без предела) | `src/main.rs:473`, `src/core.rs:1839, 2430` | При `0` читаются все страницы до конца (`usize::MAX`) |
| Поведение при `1 < pages <= 200` | обязательный постраничный обход `0..pages` | `src/core.rs:2244, 2428-2556` | В 3.6.5 (`Д-122`) обход идёт по всем страницам до конца без обрыва на `got < PAGE_LIMIT` |
| Поведение при `pages > 200` (по умолчанию) | обход первых `200` страниц + явная отметка | `src/core.rs:2442-2452` | В журнал пишется «индекс обрезан: 200 страниц из M (--index-max-pages)», в отчёте и `RESULT` ставится `index_truncated: true` |

## 4. Сверка с постановкой

| Пункт постановки (дословно) | Где в документе | Чем подтверждено | Совпадает с результатом |
|---|---|---|---|
| «А сколько страниц индекса архива может быть?» | §§1, 2 | живые замеры `showNumPages=true` 15.11.2026 (`3`, `4`, `20`, `989`) и 11.11.2026 (`5 401` в `docs/index-completeness.md`) | да |
| «может быть больше 3?» | §§1, 2, 3 | `rufence.ru` = `4`, `info.cern.ch` = `20`, `nginx.org` = `989`, `lenta.ru` = `5 401`; в `src/core.rs:73` лимит по умолчанию `200`, снимается `--index-max-pages 0` | да |

**Что не проверено и почему:** живой прогон CDX по `example.com` и `lenta.ru` 15.11.2026 не ответил за таймаут `15` с (`<urlopen error timed out>`); для `lenta.ru` использован зафиксированный замер из `docs/index-completeness.md` от 11.11.2026.
