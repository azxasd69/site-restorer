# Живая проверка вставки адреса

Автотесты покрывают разбор («буфер → хост») в `src/sanitize.rs`.
Здесь — что нужно проверить руками, потому что задействован настоящий
буфер обмена и оконный менеджер.

## Windows

1. Запустить окно, **не кликая** в поле, нажать `Ctrl+V` с адресом в буфере —
   адрес должен появиться (поле получает фокус при старте).
2. Вставить двухстрочный текст из браузера (`URL` + `Enter` + заголовок) —
   поле должно стать чистым доменом, в журнале строка `адрес: … → домен`.
3. `Shift+Insert`, `Ctrl+Shift+V` — то же поведение.
4. `Ctrl+A`, `Ctrl+C` в поле, затем вставить в блокнот — текст на месте.
5. Ввести мусор (`просто текст`) — поле не меняется, подсказка ⚠.
6. `Enter` в поле — запуск; `Esc` — снятие фокуса.

## Linux

1. `Ctrl+V`, `Ctrl+Shift+V`, `Shift+Insert` — вставка и разбор.
2. Выделить адрес в браузере и нажать среднюю кнопку над полем — вставка
   из PRIMARY (X11/Wayland).
3. Проверить в русской раскладке: `Ctrl+V` не зависит от раскладки.

## Диагностика

`SR_DIAG=<файл>` пишет в файл события клавиш и вставок (`key:V ctrl=true`,
`paste:96`, `site:prokupol.ru`) — удобно, когда окно на экране не видно
(например, под Xvfb).
