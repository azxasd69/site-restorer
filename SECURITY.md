# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 2.x | да |
| 1.x | нет |

## Как сообщить об уязвимости

**Не открывайте публичный issue.** Напишите на GitHub через
[private vulnerability reporting](https://github.com/azxasd69/site-restorer/security/advisories/new)
или личным сообщением владельцу репозитория.

В письме укажите:

- версию и разрядность (x64/x86);
- шаги воспроизведения;
- что происходит и чем это опасно;
- при возможности — минимальный пример.

Ответ в течение 7 дней, исправление — по сложности, обычно в течение 30 дней.

## Область действия

Приложение работает локально и не имеет серверной части. Оно:

- ходит только на `web.archive.org` (CDX и replay);
- не отправляет никуда ваши данные, кроме адреса сайта в запросах к архиву;
- не хранит учётные данные;
- не устанавливает службы, не пишет в реестр, не требует прав администратора.

Потенциально значимые классы проблем:

- обход ограничений путей при формировании имён файлов (path traversal);
- некорректная обработка архивных данных, ведущая к перезаписи файлов;
- утечка содержимого за пределы выбранной папки.

## Что не является уязвимостью

- Предупреждение SmartScreen для неподписанного exe.
- Отсутствие восстановленных файлов, которых нет в архиве.
- Ограничения скорости со стороны Internet Archive.
