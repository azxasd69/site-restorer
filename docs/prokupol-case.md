# Кейс: восстановление prokupol.ru

Практический пример, с которого начался проект.

## Исходная ситуация

- Домен `prokupol.ru` резолвится (45.130.41.115, Beget), но TCP 80/443 не отвечает.
- Сайт на 1С-Битрикс + шаблон Aspro Max, каталог товаров, блог, PDF-каталоги.
- Резервных копий нет, доступ к хостингу утрачен.

## Что показал архив

| Показатель | Значение |
|---|---|
| Уникальных URL в CDX | 1638 |
| Снимков на эти URL | 9476 (2016–2026) |
| HTML-страниц | 1168 |
| CSS / JS | 232 |
| Изображений | 204 |
| PDF | 8 |

## Результат

| Метрика | Значение |
|---|---|
| Скачано | 1609 из 1638 (98,2 %) |
| HTML-страниц | 1164 из 1168 |
| Каталог | 1042 из 1044 |
| Объём копии | 315 МБ |

## Что не восстановилось и почему

- **Картинки товаров.** В архиве их просто нет: проверка по деревьям
  `/images`, `/upload`, `/cache`, `/templates` дала 20 + 62 + 39 + 46 + 48
  уникальных файлов — все уже в копии. Остальные 2510 изображений, на которые
  ссылаются страницы, не сохранялись ни разу: CDX не содержит ни одной записи,
  а replay отдаёт 404 для любого года.
- **Динамика Bitrix.** Корзина, авторизация, поиск, AJAX-фильтры каталога —
  в статике не работают.
- **Кэш шаблона.** Имена файлов содержат хэш сборки; при несовпадении
  подставляется файл того же типа — стили сохраняются, версия может отличаться.

## Вывод

Веб-архив хорошо покрывает текстовый контент и структуру, но почти не хранит
изображения товаров и динамические разделы. Для полного восстановления нужен
бэкап хостинга; архив — единственный путь, когда бэкапа нет.
