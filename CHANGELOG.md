# Changelog

## 3.1.3 — 2026-11-11

Релизный процесс приведён к одной схеме; разработка только на Rust.

**Осталась одна реализация.** Python (`legacy/python`) и Go (`ports/go`) переведены
в архив: их джобы убраны из CI, сборки больше не попадают в релиз, в каталогах
и README стоит пометка «архив». Код оставлен как история.

**Имена файлов.** Единая схема `SiteRestorer-<os>-<arch>[-cli][.exe]`, без версии
в имени — ссылки `releases/latest/download/<имя>` постоянны:

| Было | Стало |
|---|---|
| `SiteRestorer.exe` | `SiteRestorer-windows-x64.exe` |
| `SiteRestorer-x86.exe` | `SiteRestorer-windows-x86.exe` |
| `SiteRestorer-rust-win-cli-x64.exe` | `SiteRestorer-windows-x64-cli.exe` |
| `SiteRestorer-rust-win-cli-x86.exe` | `SiteRestorer-windows-x86-cli.exe` |
| `SiteRestorer-rust-linux-cli` | `SiteRestorer-linux-x64-cli` |
| `SiteRestorer-rust-linux-gui` | `SiteRestorer-linux-x64-gui` |
| `site-restorer-linux-x64.tar.gz` | `SiteRestorer-linux-x64.tar.gz` |

**Гейты релиза:** тег обязан совпадать с версией в `Cargo.toml`; у каждого
бинарника проверяются `--version` и лимит размера; в релизе 8 файлов вместо 15.
Релиз-ноты берутся из этого файла, а не из списка коммитов.

**Тулчейн закреплён** (`rust-toolchain.toml`, 1.99.1) — и локально, и в CI,
чтобы сборка не зависела от того, какой stable попал на раннер.

**Документация:** [docs/RELEASE.md](docs/RELEASE.md) — что выпускаем, как называем,
как нумеруем, как собираем, что делать при ошибке. README и BUILD.md обновлены.

## 3.1.2 — 2026-11-11

Инструменты Rust-разработчика: проверки шире, найденное исправлено.

- `cargo clippy -D warnings` — 32 замечания: 28 исправлены автоматически
  (`collapsible_if` и подобные), остальные вручную (мёртвое поле, крупный вариант
  `enum` завёрнут в `Box`, кортеж из пяти элементов заменён типом `Fetched`).
- `cargo nextest` — быстрый прогон, 50 тестов.
- `cargo audit` — 313 зависимостей, уязвимостей нет.
- `cargo deny` + `deny.toml` — лицензии, запрет wildcard-зависимостей и сторонних
  источников; дубли версий — предупреждение.
- `cargo machete` — неиспользуемых зависимостей нет.
- `typos` + `typos.toml` — опечаток нет.
- `cargo bloat` — карта размера: CLI 1,8 МБ (TLS-стек ≈ 340 КБ), GUI 6,2 МБ
  (`fearless_simd` + `vello_cpu` ≈ 1,5 МБ).
- `cargo mutants` по `src/puny.rs`: было 32 непойманных мутанта, после добавления
  эталонных векторов, границ длин и длинной CJK-метки осталось 6 из 125.
- ETA снова показывается рядом с процентом: строка в словаре осталась после
  редизайна, а интерфейс её не выводил.

CI: `fmt --check`, `clippy -D warnings`, `nextest`, `audit`, `deny`, `machete`,
`typos`, кэш сборки, инструменты через `taiki-e/install-action`.

## 3.1.1 — 2026-11-11

Вставка адреса из буфера обмена: разбор, комбинации, паритет с версией на Python.

- Поле адреса получает фокус при старте — `Ctrl+V` работает без клика.
- Вставка сразу разбирается: текст чистится (BOM, невидимые символы, переводы
  строк, кавычки, `<...>`, markdown-ссылки), поле заменяется доменом, в журнал
  пишется `адрес: <было> → <стало>`.
- Подсказка обновляется сама через 0,4 с после последней клавиши, уход фокуса
  нормализует поле, `Enter` запускает прогон, `Esc` снимает фокус.
- `Ctrl+Shift+V` работает везде, `Shift+Insert` — и на Linux; средняя кнопка мыши
  вставляет PRIMARY-выборку и разбирается тем же путём.
- На Windows вставка и копирование переведены на собственный слой WinAPI
  (`src/clip.rs`): встроенный путь получал `Ctrl+V`, но не читал буфер другого
  процесса.

## 3.0.7 — 2026-11-11

## 2.4.2 — 2026-11-09

- Исправлено: страницы и CSS, сохранённые в cp1251 (или другой объявленной
  кодировке), теперь декодируются по объявлению и перекодируются в UTF-8,
  а `<meta charset>` и `@charset` приводятся к utf-8. Раньше браузер показывал
  кракозябры вместо текста.
- Исправлено: атрибуты без кавычек (`src=/img/a.png`) переписываются в локальные
  пути — раньше такие ссылки оставались абсолютными и вели в корень сервера.
- Исправлено: переиспользование закрытого keep-alive соединения определяется по
  `sock is None`; атрибута `_closed` в стандартной библиотеке нет, поэтому прежняя
  проверка не срабатывала ни разу.
- Исправлено: проверка ссылок учитывает одинарные кавычки, а не только двойные.
- Добавлены тесты этапа сборки: кодировки, атрибуты без кавычек, подсчёт битых ссылок.
